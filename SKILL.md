# Semantic Deduplication Stream Filter

## Description
Streaming semantic text deduplicator using Jaccard token overlap and sliding window hashing to eliminate redundant search snippets.

## Compatibility
- MCP Version: 2025-12-11
- Python: >=3.10 (Standard Library only)
- Supported Platforms: Claude Desktop, Cursor, LobeChat, Smithery

## Tools
Refer to `client.py` and `mcp_server.py` for full JSON-RPC tool signatures.
